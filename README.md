# Mylapore Cafe — interactive website concept

A cinematic, scroll-driven single-page site for Mylapore Cafe (77 King Street East, Oshawa), a pure vegetarian South Indian cafe.

- `index.html` – the complete site (images embedded, no build step)
- `src.html` + `assets/` – editable source; images are referenced as `{{img:N}}`

Hosted with GitHub Pages.
